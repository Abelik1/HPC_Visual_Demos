# Default pictures for Neural image compression

Every image in this folder (JPG, PNG, WebP or GIF) is offered as a one-click
default in demo mode's "Pick a picture" row. Drop your own photos in here
before demo day; they appear on the next page load, named after the file
(`my_dog.jpg` becomes "My dog").

Pictures are centre-cropped to a square in the browser and sent to the run
like an upload, then squeezed to the resolution the visitor chose.

The seed set is the Hubble Deep Field (NASA, PIA12110) and preview renders of
this project's own simulations.
